# Feedback Admin

A MERN stack admin panel for managing course feedback.

## Features

- View course feedback on the dashboard
- Add feedback with course details, comments, and a rating
- Update and delete feedback
- Store feedback in MongoDB Atlas

## Project folders

- `frontend` — React app
- `backend` — Express API and MongoDB connection

## Run the backend

Open a terminal in `backend` and run:

```bash
npm install
npm run dev
